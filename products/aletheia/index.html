Both buttons do the same thing, and the app says so out loud. Where a toolchain has its own cleanup command, both routes are literally brew cleanup — there is no version of this you cannot do without us.

What it knows that a size chart doesn't

Ranking folders by size finds your video library. These are the things that only show up if you know where to look.

01

Where developer disk goes

Extension churn duplicated across three install locations, sparse disk images that lie about their size, orphaned build output, device support for phones you no longer own.

02

Memory as macOS means it

Configured allocation rather than RSS, swap reported with its total, load average. Never "free RAM", which on this platform is not a health metric at all.

03

What it cannot see

Without Full Disk Access it cannot measure Trash, Safari, Mail or Messages — so it says that, instead of quietly leaving them out of a total and calling it complete.

What it will not do

There is no paid tier here, so there is nothing to be gained by pretending any of this is a problem.

  • NO
    Claim space macOS already manages

    Twenty-eight registered CacheDelete services own logs, Photos caches, thumbnails and document revisions, and macOS drops them under pressure on its own. Most of what this category advertises is space the operating system already owns.

  • NO
    Touch anything whose real copy lives elsewhere

    Dropbox, iCloud, OneDrive, Google Drive, NAS mounts and every future one are reported and never deleted. A cloud folder is not a cache, however much it looks like one on disk.

  • NO
    Report a number it cannot stand behind

    Every finding is marked measured or inferred and carries the command that produced it. A figure you cannot reproduce is not evidence, it is advertising.

The guarantee

It never deletes anything whose authoritative copy is somewhere else. Everything it proposes is something your machine can rebuild on its own — and it will tell you what rebuilding costs before you decide.

Every figure on this page was measured on a single machine: one 8 GB M2 running macOS 26.5.2, build 25F84. One machine is not a study, and this page will not pretend otherwise.
